---
name: woframe
description: 用 WoFrame 带用户从定位走到成片：先确认赛道（泛流量、不露脸垂直、露脸个人 IP），再走对应流程——泛流量模仿爆款，垂直与 IP 走选题、文稿、成片三步——并在第一集把系列设置写进 Handbook。
---

运行 `node scripts/woframe.mjs setup` 检查基础工具。完整流程见 [创作流程](../../../docs/creator-workflows.md)。除 Hypit 项目命令外，以 WoFrame 仓库为当前目录运行命令。

- 开工先跑 `node scripts/woframe.mjs handbooks`，看有没有同系列的沉淀。有就 `find-handbook` 找到、`apply-handbook` 合进本集，只问本集新增的东西；没有才从头问。Handbook 按赛道存在 `handbooks/<track>/<系列名>.json`，跨赛道不套用。
- 第一轮只问赛道。不要问「你是哪个赛道」，给三个场景让用户三选一：泛流量 `traffic`、不露脸垂直 `vertical`、露脸个人 IP `persona`。拿不准时按流程里的三问分流。定完写进 `track`，后面不再问。
- **Ⅰ 泛流量照着爆款做**。定赛道后先按 [泛流量工具配置](../../../docs/environment.md#泛流量工具配置) 检查 Hypit、所用服务和参考分析能力。先问有没有想模仿的：有就问借内容、结构还是风格（可多选），收本地视频或用平台接口解析外链；没有就抓该领域近期爆款，给链接、发布日期、能核实的互动量和推荐理由，让用户选一条。选定后用 `video-use` 或 Hypit 转录并整理借鉴项，分析不可用时接受用户提供的转录或口述。把参考、借鉴项和新主题交给 Hypit 生成首版，输出目录直接指向 `output/traffic/<账号名>/`（账号名没定用 `泛流量`）；只能生成到别处就用 `deliver` 移进去。交付实际产出文件和借鉴摘要。不做系列，不锁封面。
- **Ⅱ 不露脸垂直 / Ⅲ 露脸个人 IP 共用 0-1-2**。0 收选题词：用户有成稿就先检测事实、用词和可口播性，只做局部优化，不重写不改结构；再问受众、长度节奏、平台与画幅、风格偏好。1 出初稿或差异，用户确认结构后问素材、主声轨和视觉效果（字幕、画面、第一集的封面方向）。素材放进 `public/work/<项目>/`。没交素材时，Ⅱ 可用图解或字幕，Ⅲ 可先准备提词和分镜，等必要的出镜镜头齐备再渲染。2 组装项目 JSON，跑 `check --strict`，按首集或续集的配乐流程出首版给用户审片。
- **Ⅱ 合成旁白**：定稿后，用户没有提供可用录音且确认要配音时，把每镜实际要念的定稿写入 `narrationText`。在 Apple Silicon Mac 或 Windows x64 上使用本地声线前，运行 `setup --track=vertical`；配音环境缺失时用 `setup --track=vertical --install` 补齐。没有指定声线时，按项目语言选本地 Qwen 默认声线，普通话为 Vivian。用 `voices --language=` 查看候选；已有确认的系列声线时沿用 `preferences.narrationVoice`，否则用 `narrate --sample --voice=声线1,声线2` 对同一段生成试听，选定后执行 `narrate --voice=`。宽屏和竖屏共用语音，按实测时长对齐分镜后再落依赖音频的 `cues`。已有录音沿用原文件。具体命令见[合成旁白](../../../docs/environment.md#合成旁白)。
- Ⅱ/Ⅲ [配乐流程](../../../docs/creator-workflows.md#审片后决定-bgm)：首集先出带主声轨的无 BGM 首版。用户看过后决定是否配乐、播放段落与曲目，可提供音频或让 Agent 选曲，用实际画面做对照试听。续集开工先查同系列 Handbook、可用的曲目原音频与参考成片。有已确认且可用的配乐时，按本集节奏调整入点与音量，直接用在审片版。系列默认无 BGM 时沿用无配乐。暂缺可用配乐时先出无 BGM 首版，再按需安排试听。
- Ⅱ/Ⅲ 出稿后读 [Remotion 默认动效](../../../docs/remotion-motion.md)，按讲解节奏写入 `motion`。比较或选择用同组卡片和按钮，统一底色、边框和圆角，用关系符号和局部描边指向当前重点。步骤逐项展开，数字到位后停留。相邻说明优先沿用画布、标题和已经出现的对象；确定新段落再切镜。口播先保留人物，再按需要切到小窗讲解板。出片前回看关键元素入场和接镜点。
- Ⅲ 收到露脸素材时，默认采用 [露脸口播模板](../../../docs/persona-video-template.md)：开场和总结全屏，讲关系、步骤、数字时缩到右下小窗并展示动画。可以直接使用一条连续录制，Agent 依据原片时间写各镜的 `videoStartFrame`，保留原声和人物连续性。先按内容找切换点。小窗形状默认圆角方框，可用圆形；两种都必须保留完整头部、双肩和上胸。查看每段原片并调整 `pipCrop`，圆形预留弧边空间，素材只拍到脸时保持全屏或补录。讲解板在横屏位于小窗左边、竖屏位于上方；图表、轮廓线和装饰线均留在讲解区内，检查缩放时也没有穿过小窗。
- Ⅲ 额外记住人设与关系、出镜规格、说话方式、表现验收，第一集定完就沿用，不每集重问。
- Ⅱ/Ⅲ 先多选平台与发布入口、确定主发入口和内容形式，再设置画幅；Ⅰ 只确认主发平台，画幅和封面在 Hypit 出片时定，不写 `publishingTargets`。按 [视频画幅与封面指南](../../../docs/publishing-formats.md) 推荐视频和封面各自的画幅、像素及封面来源。用户已明确的规格直接沿用。成片后检查封面裁切，交付 MP4 和可上传的封面图，或给出选帧时间点。
- Ⅱ/Ⅲ 第一集定封面方向：按 [封面风格](../../../docs/cover-styles.md) 给可选方向和样品，选定后写 `coverStyle`。后续集沿用同一套版式，只换标题、钩子和图。
- Ⅱ/Ⅲ 第一集验收后用 `save-handbook` 沉淀已确认的跨集设置。配乐是否留作系列默认，由用户听过本集效果后决定。命令将跨集设置写进 `handbooks/<track>/<系列名>.json`，同名时合并写入。系列名没定就用本集标题命名。
- 成片用 `render` 直接写到 `output/<track>/<系列名>/`，文件名由命令生成，不手写。封面图用 `deliver --cover` 放进同一目录。
- 将项目与素材放进 `public/work/` 的同一个子目录。用 `check <项目.json> --strict` 检查素材和时间轴；需对齐时用 `fit <项目.json> --write`，按分镜旁白或口播原片对齐。如果视频盖不住独立旁白，先换足够长的镜头再检查。`render` 按发布计划导出不同画幅，交给用户播放验收。逐镜核对可用 `npm run preview`。
