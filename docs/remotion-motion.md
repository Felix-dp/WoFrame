# Remotion 默认动效

Agent 在定稿后先按口播或旁白拆出有意义的画面变化，再写 `episode.json`。先确认这一句让人看到什么，再确定它出现在哪一帧。渲染器会给普通文字镜头补上标题入场和图文过渡。选择、比较、步骤和数据需要 Agent 明确写进分镜。

## 怎么编排一段讲解

| 讲到的内容 | 动效安排 |
| --- | --- |
| 引出一个问题 | 标题先落位，强调线稍后出现。关键画面使用独立元素，给它留出阅读时间。 |
| 比较、二选一 | 用 `compare`。先后揭示两张卡片，讲到选定方案时让对应的 `button` 轻按一下，用细边线、侧标和字色强调；同组卡片沿用相同的底色和圆角。用 `relation` 显示「+」「≠」或「或」，让两项之间的关系一眼可见。 |
| 从条件推到结果 | 用 `steps`。箭头随下一步出现。一个关系能在同一张板上讲清时，继续加元素，保留观众已经认识的对象。 |
| 讲数字 | 用 `metric`。数字随入场到达真实值，再停住让观众读清。已经出现并延续的数字保持原值。 |
| 口播开始解释图文 | 录好的出镜素材可从全屏切到 `speaker: "pip"`，用讲解板承接信息。若人物位置或镜头差异很大，使用 `cut` 避免生硬的缩放。 |

默认图文之间短叠化。进入明确的新段落时，可用一次轻推 `slide`。现场画面、反问或需要强调节奏时用 `cut`。同段相邻分镜如果标题、卡片位置和内容相同，沿用它们；新的内容在术语或结论说出口时出现。控制同一时刻的动效数量，画面变化完成后留出阅读时间。字幕始终独立排版，不跟卡片一起移动。

这些做法来自对三条参考片段的观察。依问三不知在约 0:17–0:27 保留讲解板和人像小窗，再把「绩点＋加分」接到排名；漫士沉思录在约 28:45–28:50 保持 P／NP 示意图，让模型移动来解释关系，约 28:55 又在旁边加上树图；小Lin说的开头用独立的标题和字幕层，约 0:40–0:44 切回口播时，字幕依然处于同一阅读区域。复看依问三不知约 0:31 处，可以看到「保研绩点 ≠ 学年绩点」用强调色单独标出关系符号。

## 项目字段

完整示例见 [episode.json](../public/examples/episode.json)。无 `motion` 的旧项目也能渲染，文字分镜会使用默认入场和叠化。

- 项目 `theme` 默认 `ink`，另有暖白底 `paper`。同一条片统一色板。
- 分镜 `motion.layout` 可用 `title`、`compare`、`steps`。窄屏自动改为纵向排列。带详细说明时优先使用两到三张卡片，重点用最短的词标出。
- `motion.beats` 每镜最多四项。每项写 `label`，可另写 `detail`、`type` 和 `at`。类型是 `card`、`button`（画面里的按钮形状）或 `metric`（再填数值 `value` 和可选的 `unit`）。`at` 是镜内相对进度，范围是 0–0.9，按出现顺序填写。省略时自动错开。例子中 3 秒分镜的 `at: 0.4` 约在 1.2 秒出现。
- 两项比较可加 `motion.relation`，支持 `+`、`=`、`≠`、`→` 和 `或`。符号在第二项出现时进入。同一讲解板内更新内容时，上一条信息会留到新内容在原位置接上。
- `motion.focus` 写 `{"beat": 1, "at": 0.65}`，从 0 开始计数，在第二张卡片出现后将它高亮。
- `motion.transition` 表示如何进入当前镜，支持 `fade`、`slide`、`cut`。图文过渡通常约 0.26–0.32 秒，短镜头自动缩短。全屏素材之间默认切镜。
- `motion.speaker: "pip"` 需要场景的 `video`，主画面改为讲解板，人物缩到右下角，仍使用原场景的声轨。用同一条素材来回切换时，按 [露脸口播模板](persona-video-template.md) 填 `videoStartFrame`。小窗支持圆角方框和圆形。按口播模板取景，保留完整头部、双肩和上胸。
- 所有动效由帧驱动。叠化只保留上一镜的静态图文层，旁白、原声、字幕的开始帧和视频总帧数保持按原分镜累加，短镜头会压缩单个动效。

## 出片前检查

1. `check --strict` 检查存盘后的项目，并在 `fit --write` 对齐音频后重新看关键字与动效是否同拍。
2. 至少看三个位置：第一张卡入场、讲到选择或结论的瞬间、跨镜边界。检查是否出现空白、文字冲突、卡片跳位，字幕与小窗是否互挡。
3. 同片有横竖两版时分别看。复杂图表优先在一镜内逐步解释。四张卡或长说明挤不下时，拆段再审片。
