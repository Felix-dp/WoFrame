# 露脸口播默认模板

博主可以提交一条完整口播。Agent 按说话内容决定什么时候全屏、什么时候用右下角小窗，并将解释内容写进分镜。也可以提交逐段录好的素材。

| 段落 | 默认画面 | Agent 要处理的内容 |
| --- | --- | --- |
| 开场、经历、观点 | 真人全屏 | 保留眼神和口播节奏，用字幕承载原话。 |
| 比较、数字、步骤 | 真人缩到右下，图解占主画面 | 按说到的词依次揭示信息，让观众能边听边看。 |
| 概念接着讲 | 延续右下小窗 | 更新关键图文，保留可复用的标题和卡片。 |
| 总结、提问、行动提示 | 小窗展开回全屏 | 让观众重新看到人物表情。 |

## 用一条录制开始

1. 将素材放在 `public/work/<项目>/`。使用 [露脸项目样例](../public/examples/persona.template.json) 作为起点，替换文件名、字幕、图解和时间。样例中的 `presenter.mp4` 由创作者提供。
2. 根据原片、逐字稿或可核对的时间码划分讲解段落。每镜的 `videoStartFrame` 是原片起点，`frames` 是该段时长，两者都按项目 FPS 计算。30 FPS 下，从原片 2.2 秒开始用 `66`，接下来的 3.6 秒用 `108` 帧，下一镜从 `174` 开始。同一条素材中有意跳剪时，填实际起点。
3. 全屏段直接写 `video`。讲解段加 `motion.speaker: "pip"`，并按 [默认动效](remotion-motion.md) 填比较卡片、步骤、数字或字幕。相邻镜头的素材位置接得上时，切换布局会继续播放同一个视频和原声。换了机位或跳剪幅度大时，可以设置 `motion.transition: "cut"`。
4. 运行 `node scripts/woframe.mjs check public/work/<项目>/episode.json --strict`。再用 `npm run preview` 检查全屏、小窗、回到全屏三个位置，确认小窗内看得到完整头部、双肩和上胸，字幕和图解留在小窗之外。最后用 `node scripts/woframe.mjs render public/work/<项目>/episode.json` 出片。

分镜单独拍、每个文件刚好对应一镜时，可以省略 `videoStartFrame`。口播原声默认随片播放，填入独立 `audio` 的那一镜会用该音轨。对明确截取的原片范围，`fit` 保留已有画面时长；有独立旁白时可按旁白重算，并检查原片剩余帧数是否足够。全屏尽量采用匹配目标画幅的素材。

## 小窗取景

- 系列默认用圆角方框（`preferences.pipShape: "rounded"`），也可以设成圆形（`"circle"`）。确认后随 Handbook 保存，后续沿用。
- 需要给图解留出更多空间时，可将 `preferences.pipSize` 设为 `"small"`，并通过 Handbook 沿用。讲到新对象时可在小窗分镜加 `illustration`，填项目内 JPEG、PNG 或 WebP 的相对路径，标题放在 `text`。横屏把文字、图片和人像分区，竖屏把文字和图片上下排开。米白底配橙色可选 `theme: "renew"`。
- 小窗默认按头肩近景取景。脸横向居中，眼睛大致落在小窗高度的上方三分之一到五分之二之间。头顶留少量余量，下方保留双肩轮廓和少量上胸。圆形边缘留意头发和肩部。用同一机位切换讲解图时，沿用同一组取景参数，避免人物随换图跳动。
- Agent 预览原片后可逐镜设置 `motion.pipCrop`。例如 `{"x": 30, "y": 20, "zoom": 2}` 适合样例中偏左、站得较远的人物。默认居中（`x: 50, y: 50`），`zoom: 1` 保持原裁切大小。调小 `x` 向左取景，调小 `y` 向上取景。只在素材拍得太远时加大 `zoom`。
- 抽查小窗段的开始、中间和结束。人走动或换机位时，按片段调整取景。原片只拍到脸时，请补录能看到肩胸的素材，或让该段保持全屏。

## 小窗与讲解板的留白

参考片约 0:36–0:41 的分期图把图形主体放在小窗上方。WoFrame 为人物留独立空间：横屏的讲解板放在小窗左侧，竖屏放在上方，板框和小窗轮廓之间至少留出短边的 4%。横竖屏都把图表、装饰线和边框留在讲解区内。人物从全屏缩下去时，先到位再显示讲解板；展开回全屏时先收掉板框。小窗保留完整头部、肩膀和上胸。

审片时看全屏缩小、小窗停稳、两页讲解板交接，以及回到全屏四个位置。若标题或卡片挤不进讲解区，缩短文字或拆镜，给人物保留原来的空间。

模板参考了[依问三不知的讲解板和人像小窗](https://www.bilibili.com/video/BV1txWH6ME9G/)。源素材起点使用 Remotion 的[视频裁剪参数](https://www.remotion.dev/docs/html5-video#trimbefore)。
