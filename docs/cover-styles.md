# 定封面风格

封面不是每集重新挑一次图，而是先定一套版式，之后每集只换字和图。第一集定下来，后面十集都按它排；中途换风格，前面攒的辨识度就清零了。

## 先看样品

打开 `design/covers/index.html`，五个方向用的是同一集、同一段文字、同一画幅，只换风格；每个方向同时给了 16:9 和 3:4。点击卡片可以选定，页面底部会给出要写进 Handbook 的字段。

| | 方向 | 一句话 | 每集成本 | 最适合 |
| --- | --- | --- | --- | --- |
| A | 简·色块 | 一整块颜色、四五个字、一个角标 | 低，纯排版 | 概念讲解、清单、口播 |
| B | 科技·霓虹 | 深色底、渐变光、一个大字标题 | 中 | 工具、技术、效率、AI |
| C | 电影·学术 | 黑场、宋体大字、一张概念图 | 高，每集要一张图 | 数学、物理、经济、认知 |
| D | 切片·信息条 | 取成片一帧，上下加信息条 | 最低，选帧即可 | 口播、访谈、有真人画面 |
| E | 纸感·编辑 | 米白纸面、宋体、集数印章 | 中低 | 知识、读书、生活思考 |

## 一脉相传固定的是什么

风格就是一组固定槽位加一组可变槽位。固定槽位跨集不动，可变槽位每集替换。只说"看起来像一套"而说不清哪些固定，第二集一定走样。

固定（不许动）：

1. 骨架：安全边距、标题块的位置与最多行数、信息条高度。
2. 字体阶梯：主标题、钩子、系列名、集数各自的字号区间与字重。一张封面只用一套阶梯。
3. 色板：底色加一个强调色。强调色每集只出现一次。
4. 图形语法：允许出现的元素（纯色块、光效、一张图解、一帧画面、印章）和禁止项。
5. 常驻信息：系列名、集数、栏目或作者，位置固定。
6. 文字上限：主标题不超过 6 字，钩子不超过 14 字，关键词不超过 3 个。

可变（每集换）：主标题、钩子、关键词、概念图或静帧、集数、角标文字（如"零基础""进阶"）。

## 第一集怎么定

按顺序回答三个问题，基本只剩一个方向。

1. 每集能不能稳定产出一张"看得懂的画面"？不能 → A 或 E；能 → 下一步。
2. 主发平台的信息流是深色还是浅色？深色 → B；浅色 → E。
3. 每集有人出镜、画面本身够清楚吗？是 → D；否 → C。

零基础、要连更、靠图解讲清概念时，先按 C 做第一张，撑不住再退 A：两者骨架几乎一样，只是去掉概念图。

再按三个尺寸检查：

- 手机缩略图（约 160 px 宽）：只有主标题需要活下来，读不清就换短标题，不要换风格。
- 发布页裁切：3:4 和 16:9 分别看一遍，字和主体不能进裁切区。
- 同屏对比：把候选和同赛道三条封面并排，看能不能一眼认出是一套。

## 锁定

第一集确认后，把风格 id 写进系列 Handbook：

```json
{"version": 1, "preferences": {"coverStyle": "cinema", "ratio": "9:16"}}
```

```sh
node scripts/woframe.mjs save-handbook public/work/episode-1/episode.json
```

第二集起先运行 `apply-handbook`，`coverStyle` 随项目带下来。封面按登记表里的固定槽位排，不重新设计骨架。

泛流量支路不做系列，不写 `coverStyle`，每条封面另选；只有不露脸垂直和露脸 IP 才需要锁定版式。

## 后续集允许改什么

允许：换标题、钩子、概念图、集数、角标；同一风格内微调配色深浅，让标题在该集的具体画面里站得住。

不允许：挪标题位置、改字号阶梯、加第二个强调色、换字体、加新的装饰元素。要改就是换风格，不是改这一集。

## 什么时候可以换风格

只在三种情况下换，且整季或新一季整体换，不单集换：

1. 连续 5 集以上，主标题在缩略图里读不出来。
2. 内容形态变了，比如口播转图解、横屏转竖屏。
3. 主战场换了平台，比如 B 站转抖音。

## 生成封面

模板在 `design/covers/covers.html`，风格登记表在 `design/covers/styles.json`。用 `build.mjs` 出图：

```sh
node design/covers/build.mjs --style cinema --format 3x4 --out public/work/ep02/cover-3x4.png \
  --series 零基础经济学 --ep 02 --title 沉没成本 \
  --hook 已经花掉的，不该再算进决策 \
  --note 已经沉掉的，不参与下一次选择
```

`--format` 支持 `16x9`、`9x16`、`3x4`、`4x3`、`1x1`。C 风格的概念图用 `--figure <png|svg>` 换，D 风格的静帧用 `--still <png|jpg>` 换。不传参数运行 `node design/covers/build.mjs all` 会重出样品库中的 16:9 和 3:4 两组。

出图后仍要按手机缩略图和发布页裁切复核，再交付 JPG 或 PNG。
