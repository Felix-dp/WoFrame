# 选择视频画幅与封面

适用于 Ⅱ 不露脸垂直和 Ⅲ 露脸个人 IP。Ⅰ 泛流量由 Hypit 出片，画幅和封面在 Hypit 里定，不写 `publishingTargets`；平台表仍可用来判断主发平台。平台资料核对日期为 2026 年 11 月 14 日。

## 开拍或生成前确认规格

1. 确定主发平台、发布入口和视频形式，例如「抖音竖屏口播」或「B 站横屏教程」。一稿多发时先确定主版本，再说明哪些平台可复用视频、哪些需要调整视频构图或另备封面。
2. 给出一组推荐规格，包含视频画幅与像素、封面画幅与像素、封面来源（现有图、选帧或设计）。用户已明确的规格直接沿用。已定型的系列可沿用 Handbook 中的 `platform` 和 `ratio`，封面方案随本集发布说明记录。
3. 在策划和分镜阶段按选定画幅安排人物、字幕、图表及留白。按主平台的实际发布入口检查封面上传选项和裁切预览。每个画幅都应单独审片。

例如，做一条发抖音的竖屏口播，可先推荐 9:16（1080×1920）视频和 3:4（1080×1440）封面。拍摄时给人物上方留标题空间，成片后选一帧表情清楚的画面，试排并按发布页裁切定稿。

发布配置写在项目 JSON 的 `publishingTargets` 里，也可在 `npm run preview` 的「发布规格」里多选平台及入口、指定主发入口，再分别调整比例。画幅相同且内容相同的视频合为一个版本，封面规格按平台保留。若某平台需要不同字幕、镜头或素材，用单独的项目 JSON 预览并导出。将保存的发布配置 JSON 放在原项目目录，才能沿用相对路径的素材。

Agent 可在项目 JSON 中记录 `publishingTargets`。第一项为主发入口，每项可省略画幅以采用默认值。`render` 按这个顺序输出所有不同的画幅；若只渲染一个画幅，可传 `--ratio=9:16`。项目没有发布入口时沿用项目自身画幅。下例会得到 9:16 与 16:9 两个视频版本。

```json
{
  "publishingTargets": [
    {"profile": "douyin"},
    {"profile": "xiaohongshu", "coverRatios": ["3:4"]},
    {"profile": "bilibili", "videoRatio": "16:9", "coverRatios": ["4:3", "16:9"]}
  ]
}
```

平台入口可用 `douyin`、`wechat-channels`、`xiaohongshu`、`bilibili`、`bilibili-vertical`、`youtube` 和 `youtube-shorts`。页面中的封面像素为基础制作尺寸，YouTube 高清封面可按下表提高分辨率。

## 按平台和发布形式推荐

表内像素为 WoFrame 制作规格。封面默认值用于排版和讨论，上传时以账号实际发布页为准。

| 平台与形式 | 视频默认画幅 | 封面建议与核实结果 |
| --- | --- | --- |
| 抖音竖屏短视频 | 9:16（1080×1920） | 主页卡片可先备 3:4（1080×1440），按发布页裁切。开放平台支持指定视频帧或自定义图。上传文档同时写了「16:9」和「竖版」，9:16 是 WoFrame 的竖屏制作默认值。 [抖音上传文档](https://open.douyin.com/platform/resource/docs/openapi/video-management/douyin/create/upload) · [封面参数](https://open.douyin.com/platform/resource/docs/openapi/video-management/douyin/create/create-video/) |
| 微信视频号竖屏短视频 | 9:16（1080×1920） | 先用 3:4（1080×1440）试排，在发表页及手机预览检查裁切。腾讯发布指引展示了封面预览，公开资料暂未核实到截图中「6:7 最佳」或「9:16 必裁」的通用依据。 [腾讯视频号发表指引](https://training.tencentads.com/uploads/202406/owOSZqwE_qFRhqg.pdf) |
| 小红书竖屏视频笔记 | 9:16（1080×1920） | 主页或信息流卡片可先备 3:4（1080×1440）。小红书电商课程对笔记封面给过 3:4 建议，对商品视频笔记的独立封面则列出 16:9 或 9:16，因此以当前发布入口预览定稿。图文笔记首图可用 3:4。 [小红书电商学习中心](https://school.xiaohongshu.com/lesson/normal/af0fe7e97bb0433fac9da5d1df52b07f) |
| B 站横屏教程、长视频 | 16:9（1920×1080） | 同一设计检查 4:3（1440×1080，稿件列表）和 16:9（1920×1080，播放页）两版。若投竖屏短内容，视频可按 9:16 制作，封面仍按投稿页检查。 [哔哩哔哩客服](https://www.bilibili.com/opus/1106096748969852979) |
| YouTube 常规横屏视频 | 16:9（1920×1080） | 封面用 16:9。YouTube 建议高清自定义缩略图可做至 3840×2160。 [YouTube 视频规格](https://support.google.com/youtube/answer/6375112?hl=zh-Hans) · [缩略图说明](https://support.google.com/youtube/answer/72431?hl=zh-Hans) |
| YouTube Shorts | 9:16（1080×1920） | 有自定义缩略图入口时用 9:16。YouTube 当前帮助页说明，已验证账号可在电脑版 Studio 上传，建议 2160×3840。也可按实际发布入口选择片内帧。 [Shorts 资格说明](https://support.google.com/youtube/answer/15424877?hl=zh-Hans) · [缩略图说明](https://support.google.com/youtube/answer/72431?hl=zh-Hans) |

内容需要保留旧素材构图时可选 4:3，主体居中且投放位置适合方形时可选 1:1。WoFrame 的五种固定视频规格见 [README](../README.md)。参考截图把小红书的 1242×1660 和 1660×1242 标成了 9:16 和 16:9，实际分别接近 3:4 和 4:3。

## 选帧还是单独做封面

| 素材情况 | 处理方式 |
| --- | --- |
| 已有合适的照片、图解或栏目模板 | 沿用已有素材，按封面画幅重新排人物、标题和图表。 |
| 成片里已有能讲清主题的一帧 | 记下时间点。平台可选帧时直接选择，支持上传时也可以从审过的 MP4 提取静帧再裁切。 |
| 选帧在小尺寸下读不清、裁掉主体，或系列需要统一样式 | 单独设计封面。真人口播可用清晰表情帧或肖像照。知识视频可用核心图解、对比画面或一条短标题。缺少合适画面时再生成新图。 |

开工前先确认封面方向，首版出来后推荐一张主选并说明原因。系列第一条视频另需按 [封面风格](cover-styles.md) 从样品中选定一种版式并写入 Handbook，之后各集只换字和图。用手机缩略尺寸检查主题是否看得懂、标题是否读得清、人物和图表是否留在裁切范围内。多比例封面沿用同一主视觉，按各自画幅排版。

交付时提供审过的 MP4，以及平台可上传的 JPG 或 PNG。采用平台选帧时，交付对应 MP4 和明确的选帧时间点。成片由 `node scripts/woframe.mjs render <项目.json>` 生成并直接写入 `output/<赛道>/<系列名>/`；封面按以上流程由 Agent 或创作者另行准备。
