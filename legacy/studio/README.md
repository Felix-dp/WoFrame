# 开讲 · 本地工作台

在工作区运行 `node studio/server.mjs`，打开 http://127.0.0.1:4173。

服务端运行环境同时提供以下三个变量时，会启用 AI 定题与讲稿生成。它们由部署者配置，网页的创作者无需接触。

使用 DeepSeek 官方接口时，只需设置本机的 `DEEPSEEK_API_KEY`。默认模型为 `deepseek-flash`，可通过 `DEEPSEEK_MODEL` 指定其他模型。以下三个变量用于覆盖默认接口。

也可以在工作区运行 `& .\studio\start-deepseek.ps1`，按提示在本机终端输入密钥。输入会隐藏，脚本退出时恢复原有环境配置。浏览器顶部会显示当前运行模式。

| 变量 | 用途 |
| --- | --- |
| `STUDIO_AI_URL` | 兼容 Chat Completions 且支持 JSON 输出的完整接口 URL |
| `STUDIO_AI_KEY` | 接口令牌，只留在服务端环境 |
| `STUDIO_AI_MODEL` | 该接口支持的模型名 |

没有服务端配置时，工作台使用本地通用方向、示例讲稿和分镜提纲。真实 AI 初稿需要用户校对。

## 浏览器验收

在工作区运行 `node studio/browser-smoke.mjs "<Chrome 或 Edge 的绝对路径>" --ai`，可用本地模拟模型验证选题、写稿、改稿和回退。配置 DeepSeek 密钥或通用接口变量后，把参数换成 `--live-ai` 即可对真实模型执行同一套交互验收。测试使用「自行车速度」和「速度表」作为样例输入。它会验证页面是否收到并应用了内容，事实和教学质量仍需人工审阅。

浏览器本地保存讲稿版本和开场偏好。真人拍摄需授予摄像头与麦克风权限，也可上传已有视频。

改完开场后，可以勾选「从我改过的开场学习讲法」再保存。工作台根据文字识别「请观众预测」或「用生活例子开场」，新主题会沿用启用的偏好。偏好保存到当前浏览器，可以关闭或清除。

真人模式按分镜切换提词，分别录制、上传、预览、下载或删除。修改某段讲稿时，工作台会提示该段可以重录。工作台把素材保存在当前浏览器，使用同一地址重新打开可以恢复最近保存的项目素材。浏览器存储不可用时，页面会提示及时下载。

各分镜素材齐全后，可以导出整条口播。工作台在浏览器里按分镜顺序合成画面和原声。可选择烧录讲稿字幕，字幕按片段时长均分，需要逐字同步的片段目前仍要另做对齐。

动画可直接导出无声版。Windows 默认使用已安装的系统普通话语音，可离线生成。其他系统默认使用 `edge-tts`。在 Windows 上也可以设置 `STUDIO_TTS_PROVIDER=edge` 切换到 Edge 语音。使用 Edge 时需安装 `edge-tts` 并确保命令可通过 PATH 找到，或用 `STUDIO_TTS_COMMAND` 指定其可执行文件路径。Edge 默认音色为 `zh-CN-XiaoxiaoNeural`，可通过 `STUDIO_TTS_VOICE` 更改。工作台按实际音频时长安排分镜，同一会话内复用已经合成的旁白。导出格式以浏览器支持为准。

同一页面会话内，动画导出会缓存渲染好的各镜。修改一镜后再次导出时，只重新生成改动的镜头，再合成整条视频。导出结果会显示新渲染和复用的镜头数。

运行服务的环境里如果有支持 `libx264` 和 `aac` 的 FFmpeg，工作台会显示「导出为 MP4」。可将 FFmpeg 加入 PATH，或把 `STUDIO_FFMPEG` 设为可执行文件的绝对路径。转码暂不可用时，页面会下载浏览器生成的 WebM。
